# Test fixtures: X-Plane Scenery Gateway excerpts

`YBBN.apt.dat` and `YTWB.apt.dat` are single-airport excerpts of X-Plane 12's Global Airports `apt.dat`, which
comes from the [X-Plane Scenery Gateway](https://gateway.x-plane.com/). Gateway airport data is licensed under the
GNU General Public License (version 2 or later), not under this repository's MIT licence.

They are used only by the tests and are not part of the XPConnect release. At run time XPConnect reads each
user's own X-Plane installation.
